
# Expense Tracker

A beginner-friendly command-line expense tracker built using Python.

## Features

- Add expenses with category, amount, and description
- View all expenses
- Search expenses by category
- Delete a specific expense
- Calculate total spending
- Calculate category-wise spending
- Save and load expenses using JSON
- Input validation

## Technologies Used

- Python
- Lists and Dictionaries
- Functions and Loops
- JSON File Handling
- Git and GitHub

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run:

   python main.py

## Data Storage

Expenses are stored locally in `expenses.json`.
